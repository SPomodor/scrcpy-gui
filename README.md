# Android Desk

Windows x64 приложение на C# / WinUI 3 для управления Android через локальный комплект scrcpy 5.0.1.

## Запуск

Дважды нажмите `Android Desk.cmd` или откройте `dist/AndroidDesk/AndroidDesk.exe`. При переносе скопируйте **всю** папку `dist/AndroidDesk`. .NET и Windows App SDK включены в сборку; MSIX и права администратора не нужны. Требуется Windows 10 2004+ x64, интерфейс рассчитан на Windows 11.

Включите USB-отладку, подключите телефон и разрешите отладку с компьютера. Уже подключённые к ADB устройства по Wi-Fi также обнаруживаются. Приложение проверяет список каждые две секунды. Сопряжение Wireless Debugging выполняется отдельно.

## Главное окно

Экран занимает всю рабочую высоту окна, без шапки, нижней строки и постоянной панели настроек. При первом подключении ширина окна подстраивается под пропорции телефона и панель быстрых действий; высота — под рабочую область монитора, без перекрытия панели задач. Пропорции сохраняются без обрезания изображения. Окно можно менять вручную; кнопка подгонки внизу панели возвращает размер по телефону.

Справа находится панель шириной 44 логических пикселя с кнопками 34×34:

- Телефон: отдельное окно выбора устройства с моделью, типом соединения и серийным номером; список обновляется автоматически.
- Подключить / отключить текущий телефон.
- Назад, домой, недавние приложения, громче, тише, питание.
- PNG-скриншот.
- Начать / остановить запись; во время записи появляется небольшой таймер.
- Подогнать окно по телефону.
- **⋯**: отдельное окно настроек.

При переключении телефона текущая запись корректно завершается. При нескольких устройствах выберите нужное в окне «Телефоны» и нажмите «Подключить».

Сообщение о сохранении скриншота или видео показывается отдельным небольшим уведомлением поверх изображения и исчезает через 4 секунды; ошибки — через 8 секунд. Кнопка «Показать файл» открывает Проводник. Постоянного журнала и строки состояния в интерфейсе нет.

## Настройки и запись

В окне ⋯ доступны:

- Длинная сторона изображения: **720, 960, 1280, 1600, 1920, 2560 px** или оригинальное разрешение. Это ограничение длинной стороны, а не строгое обозначение 720p/1080p.
- До 30 / 60 / 90 / 120 FPS. Фактическая частота зависит от устройства и изменений изображения.
- Битрейт 1–64 Мбит/с.
- Формат записи **MP4** или MKV; видео H.264, звук AAC.
- Звук в записи, автоподключение и отдельное окно scrcpy.
- Кнопка открытия папки видеозаписей.

По умолчанию новые настройки записи — **MP4 со звуком**. Обычная трансляция идёт без звука; во время записи включается захват аудиовыхода телефона, воспроизведение на ПК отключено. Микрофон не записывается. Захват звука scrcpy требует Android 11+; на Android 11 телефон должен быть разблокирован. Захват защищённого контента может ограничиваться Android или приложением. Если AAC/аудиозахват не работает, запись не продолжается молча без звука: обычная трансляция восстанавливается, выводится ошибка; звук можно выключить в настройках.

Начало и остановка записи коротко перезапускают scrcpy: готовая программа принимает `--record` при запуске. «Применить» также перезапускает текущую трансляцию. Во время записи изменять настройки нельзя. Один процесс scrcpy отвечает за экран, ввод и запись. MKV/MP4 завершается через `WM_CLOSE` SDL-окну, приложение ждёт до 8 секунд. При зависании процесс принудительно закрывается с предупреждением о возможном повреждении записи. Обычное закрытие приложения также финализирует запись.

Видео: системная папка `Видео/AndroidDesk`. PNG в исходном разрешении: `Изображения/AndroidDesk`. Скриншот получается бинарным `adb exec-out screencap -p`. Статичный экран может передавать мало кадров; длительность файла и таймер иногда отличаются.

## Встраивание и ввод

Готовое SDL-окно scrcpy превращается в дочерний HWND через Win32 `SetParent`. Размер и DPI синхронизируются с выделенной областью WinUI. Собственный движок трансляции не используется. Щёлкните по экрану телефона для мыши и клавиатуры. Alt+H — домой, Alt+B — назад. Стандартный SDK-ввод scrcpy имеет ограничения Unicode; для русского текста используйте синхронизацию буфера обмена и Ctrl+V.

Встраивание внешнего процесса зависит от SDL, драйверов и DPI. Если на другом ПК возникают проблемы, включите отдельное окно в настройках. Настройки, выбор устройства и уведомления сделаны отдельными окнами, чтобы их не перекрывало нативное видео. В отдельном режиме доступен Alt+F; во встроенном режиме полный экран scrcpy может нарушить его привязку.

На некоторых realme/Xiaomi управление требует дополнительного разрешения отладки производителя. Приложение не меняет настройки безопасности телефона. Для минимальной задержки используйте USB; дополнительных видеобуферов нет. Устойчивая частота и задержка зависят от телефона и сети.

## Сборка и проверка

Нужны .NET SDK 8+ x64, Windows SDK и доступ к NuGet при первом восстановлении. Для Visual Studio откройте `AndroidDesk.sln` с поддержкой разработки WinUI/C#.

```powershell
.\build.ps1                  # Debug
.\build.ps1 -Publish         # Переносимая Release в dist/AndroidDesk
.\run.ps1                    # Запуск Release
```

Без PowerShell-скриптов:

```powershell
dotnet publish .\AndroidDesk\AndroidDesk.csproj -c Release -p:Platform=x64 -o .\dist\AndroidDesk
& '.\dist\AndroidDesk\AndroidDesk.exe'
```

Закройте приложение перед пересборкой его выходной папки. Комплект `scrcpy/` включён в локальный Git и копируется при сборке. XBF/PRI WinUI явно копируются после Publish — проверено запуском именно из `dist`.

Интеграционная проверка захвата реального MP4/AAC, без имитации ADB или scrcpy:

```powershell
dotnet run --project .\AndroidDesk.Smoke -- DEVICE_SERIAL
```

Она запускает отдельную четырёхсекундную сессию scrcpy на выбранном устройстве, сохраняет `Видео/AndroidDesk/Smoke_AAC_*.mp4` и корректно завершает её. Список устройств: `scrcpy/adb.exe devices -l`. Для проверки нужны подключённый телефон и рабочий аудиозахват. Результаты ручных и интеграционных проверок — в `VERIFICATION.md`.

Настройки: `%LOCALAPPDATA%/AndroidDesk/settings.json`. Диагностика: `app.log` в той же папке; журнал сохраняется локально и может содержать идентификаторы устройств. Приложение не завершает общий ADB-сервер. Лицензии стороннего комплекта — в `scrcpy/LICENSE.txt`.

Исходники: `MainWindow.xaml` — компактный интерфейс; `MainWindow.xaml.cs` — состояние и жизненный цикл; `ToolWindows.cs` — настройки, выбор телефона, уведомления; `Services.cs` — ADB/scrcpy и настройки; `Native.cs` — Win32. Внешние аргументы передаются через `ProcessStartInfo.ArgumentList`, без командной оболочки.
