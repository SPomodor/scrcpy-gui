# Проверка обновления интерфейса · 21 октября 2026

Среда: Windows 11 x64, .NET SDK 10.0.301, проект .NET 8 / Windows App SDK 1.8.260921001, scrcpy 5.0.1, реальный realme RMX5070 с Android 15 по USB.

## Сборка

- Debug: успешная сборка, 0 ошибок, 0 предупреждений.
- Release: успешная публикация в `dist/AndroidDesk` с .NET, Windows App SDK, XBF/PRI приложения и локальным комплектом scrcpy.
- Реальное главное окно проверено после запуска собранного EXE: узкая панель, изображение на всю высоту рабочей области, без прежней шапки, нижней строки, журнала и постоянных настроек.

## Проверки на реальном устройстве

- Автоподключение к USB-устройству; живое изображение встроено в WinUI. Direct3D 11 / D3D11VA подтверждены журналом.
- Главное окно подстроено под пропорции телефона: экран без внутренних отступов, справа панель 44 логических px, кнопки 34×34.
- Кнопкой ⋯ открыто отдельное окно настроек; проверены поля разрешения, FPS, битрейта, MP4/MKV, звука, отдельного окна и автоподключения.
- В списке разрешений проверены 720, 960, 1280, 1600, 1920 и 2560; оригинал также предусмотрен. Через интерфейс выбрано и применено 960. Настройка сохранена в JSON, новая текстура scrcpy — 432×960.
- С панели запущена и остановлена запись MP4 с включённым звуком. scrcpy штатно сообщил `Recording complete`. В реальном файле обнаружены H.264 и AAC, видеокадры декодированы, декодировано 975872 аудиосэмпла. Обычная трансляция восстановлена после остановки записи.
- Отдельная интеграционная проверка `AndroidDesk.Smoke` использовала реальные ADB и scrcpy: 720 px / 30 FPS / 2 Мбит/с, четырёхсекундный MP4. PyAV подтвердил H.264-видео и AAC-аудио: 13 кадров видео, 189 аудиокадров / 193536 аудиосэмплов. Тест оставлен в исходниках для повторного запуска с серийным номером устройства.
- PNG-скриншот сделан кнопкой на панели. Уведомление «Скриншот сохранён» с именем файла и кнопкой «Показать файл» появилось поверх видео отдельным окном; через несколько секунд исчезло. Постоянной нижней строки нет.
- Кнопка телефона открыла отдельный выбор устройства с моделью, USB и серийным номером; текущее устройство выделено.
- Штатное закрытие главного окна закрыло окно выбора и принадлежащий приложению процесс scrcpy. Общий ADB-сервер не завершался.

В этой проверке не менялись громкость и блокировка телефона. Одновременно подключённого второго телефона не было: выбор проверен с одним реальным устройством. Сценарий ошибки аудио на старом Android, длительная запись, несколько мониторов/DPI и 90/120 FPS отдельно не проверялись. Сквозная задержка не измерялась. AAC-дорожка и её декодирование подтверждены; независимая проверка слышимости конкретного приложения не проводилась.

Для декодирования использовался PyAV из временной папки компьютера, он не входит в приложение. MP4/AAC реализован флагами штатного scrcpy (`--audio-codec=aac`, `--require-audio`, `--no-audio-playback`), без собственного движка.

История исходного интерфейса и его проверок сохранена в первом Git-коммите. Сборки, личные настройки, пользовательские записи и скриншоты в Git не включены.
