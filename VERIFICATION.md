# Проверка 21 октября 2026

Среда: Windows 11 x64 (сборка 26200), .NET SDK 10.0.301, проект .NET 8 / Windows App SDK 1.8.260921001. Локальный scrcpy 5.0.1 / SDL 3.4.18. Реальный realme RMX5070, Android 15, ADB по Wi-Fi.

Проверено на устройстве через собранное приложение:

- Телефон обнаружен автоматически, имя и тип Wi-Fi показаны в списке.
- Реальная трансляция внутри WinUI-окна через дочерний HWND. В журнале подтверждены Direct3D 11, D3D11VA и текстура 864×1920.
- Кнопка «Домой» отправила ADB-команду и открыла домашний экран.
- Щелчок мышью по экрану открыл системный поиск телефона; его диалог согласия не принимался. Клавиатурная команда scrcpy Alt+H вернула домашний экран.
- Запись запущена и остановлена кнопкой. scrcpy сообщил `Recording complete`. MKV прочитан через PyAV, все 28 кадров H.264 декодированы, размеры 864×1920, временные метки возрастают. Почти статичный экран передал только 2.612 секунды видеокадров при более долгом времени работы таймера — скринкаст scrcpy передаёт изменившиеся кадры.
- PNG получен кнопкой приложения: 3 135 058 байт, подпись PNG проверена сервисом, целостность файла дополнительно проверена Pillow.
- Режим «Отдельное окно scrcpy» применён: появилось самостоятельное окно с живым экраном, внутри основного окна показана соответствующая подсказка.
- Во время проверки Wi-Fi-соединение телефона перешло в offline. Приложение обработало отключение без падения. После этого телефон отказал в повторном TCP-подключении; финальная переносимая сборка оставлена открытой в ожидании устройства.
- Штатное закрытие приложения завершило его процессы; общий ADB-сервер остался доступен.

Сборка и упаковка:

- Debug собран без ошибок и предупреждений.
- Release опубликован командой `dotnet publish AndroidDesk/AndroidDesk.csproj -c Release -p:Platform=x64 -o dist/AndroidDesk`.
- При проверке публикации выявлено, что стандартный publish не включил сгенерированные XBF/PRI приложения. В csproj добавлен `PublishWinUIResources`, который копирует их после Publish. После исправления переносимый EXE запущен **из dist**, окно отрисовано, процесс отвечает. Это проверка реального запуска, а не только успешной компиляции.
- Финальная Release-публикация прошла успешно. .NET, Windows App SDK и комплект scrcpy присутствуют в выходной папке.

Пределы проверки: реальная передача экрана, ввод и запись проверялись в Debug; финальный Release проверен на запуск, отрисовку и ожидание устройства после отключения телефона. Другие модели, USB, поворот экрана, несколько DPI/мониторов, длительная запись, USB-переподключение и параметры 90/120 FPS отдельно не проверены. Сквозная задержка и устойчивая частота кадров не измерялись. Кнопки громкости и питания реализованы стандартными Android keyevent, но при проверке состояние громкости/блокировки пользователя не менялось.

PyAV был установлен во временную папку компьютера только для проверки видео; он не нужен приложению, не входит в проект и не включён в дистрибутив.
